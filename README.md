# Вика · Литература

Персональный учебный тренажёр: https://terrifickook.github.io/vika-literatura/

Статический сайт без регистрации, аналитики и облачной базы. Последняя согласованная архитектура: GitHub Pages + IndexedDB + экспорт/импорт JSON. Никаких Firebase, VPS или Docker. PDF.js поставляется локально, без CDN.

## Для Виктории Радиковны

1. Откройте «Материалы для чтения»: скачайте два оригинала по ссылкам ФИПИ и выберите их кнопкой добавления. Это нужно один раз на каждом устройстве.
2. Нажмите «Продолжить». Тексты, условия и ученические работы читаются прямо на странице: можно увеличить шрифт или включить «Как в оригинале» для просмотра подчёркиваний и таблиц.
3. Выполните задание, дождитесь «Сохранено на этом устройстве», затем откройте разбор.
4. Для другого устройства откройте «Перенос прогресса»: скачайте JSON здесь и импортируйте там. Оригиналы пособий в JSON не включены.

Борис встречает на главной странице и отвечает на нажатие. Во время заданий всплывающий кот скрыт. «Тихий режим» отключает анимацию; системная настройка уменьшения движения учитывается автоматически.

Автоматической межустройственной синхронизации нет. Очистка данных браузера/приватный режим может удалить прогресс. Импорт не перезаписывает разные версии молча: обе сохраняются в разделе «Мои ошибки». Файл экспорта содержит личные ответы, не публикуйте его в Git.

## Содержание

- 2 полноформатные учебные сборки ФИПИ-2026 по 11 заданий, а не 2 официальных варианта МЦКО; 12 кратких ключей и 10 письменных заданий. Второй набор оставлен для контрольной попытки; тематический перечень сочинений общий.
- 10 реальных ученических работ с опубликованными экспертными оценками ФИПИ (включая сочинение), чтение внутри сайта после однократного добавления оригинала.
- 10 авторских случаев проверки по упрощённой шкале, отдельно от официальных.
- 12 авторских коротких упражнений на прозу, лирику, сопоставление и типичные ошибки.
- Маршрут на четыре дня, черновики, подсказки, повторные попытки, самооценка, экспорт ответа, учебный печатный бланк, непрерывный таймер/таймер с паузой, возврат к вопросу и подтверждение сдачи.

Полные PDF, современные условия, ученические ответы и комментарии не скопированы в репозиторий. Они извлекаются из добавленного пользователем оригинала в его браузере. Сервер ФИПИ не разрешает прямую загрузку с другого сайта (CORS); поэтому требуется однократный выбор файлов. В репозитории есть только карты координат, метаданные, ключи и классические фрагменты Гончарова/Островского в общественном достоянии. Выбранные PDF проверяются по SHA-256: другая редакция не принимается, чтобы не показывать неверные страницы.

Чтение работает без сети после первого открытия сайта и добавления материалов. Удобный текст не передаёт все шрифтовые выделения оригинала; для отмеченных экспертом ошибок и сложных таблиц используйте «Как в оригинале». В интерфейсе ученический ответ отделён от комментария; в репетиции разбор доступен после сдачи. Сам PDF остаётся доступным пользователю целиком.

Профиль ЕГЭ-2026 подтверждён; точная актуальная демоверсия, длительность и способ ввода части 2 МЦКО не подтверждены из-за недоступности его файлов. Репетиция оценивания помечена учебной. Результат не означает официальный уровень и не гарантирует сдачу. Общий балл при непроверенных письменных ответах не рассчитывается. Подробнее: [SOURCES.md](SOURCES.md).

## Локальный запуск

Node.js 24.16 или новее. Установка npm-пакетов не требуется.

```powershell
npm start
# http://127.0.0.1:4173
npm test
```

GitHub Actions проверяет тесты и публикует только каталог `public`. Данные IndexedDB не попадают ни в Git, ни на сервер GitHub. Service Worker сохраняет оболочку и PDF.js. Библиотека PDF хранится отдельно в `vika-reading-library-v1`. PDF.js 6.4.299: лицензия Apache-2.0 в `public/vendor/pdfjs/LICENSE`; npm devDependency фиксирует источник поставляемой версии.

## Проверка

Автотесты проверяют состав наборов, ключи, отсутствие автоматической оценки сочинений, время и валидацию импорта. Браузерная проверка: русский текст 23 000 символов, обновление и повторное открытие вкладки, офлайн-ввод и офлайн-перезагрузка, перенос JSON в независимый контекст, сохранение двух конфликтующих версий, навигация/альтернативы/сдача репетиции, ширины 1440 и 390 px. Скриншоты в локальном `output/playwright` (не в публичном репозитории).

Дополнительно проверены 35 карт чтения, все 44 выбранных условия/альтернативы и ученические фрагменты, отсутствие комментариев в ученических фрагментах, чтение после офлайн-перезагрузки, исходный вид, критерии, скрытие экспертного разбора до сдачи, обращение Бориса, сохранение тихого режима и отсутствие горизонтального переполнения на 360 px. 10 автотестов проходят.

Физический Android, его экранная клавиатура, фактическая печать на принтере не проверены. При недоступности IndexedDB приложение не разрешает начать работу с несохраняемыми ответами.

Иллюстрация `public/assets/boris.png` создана встроенным генератором изображений по двум предоставленным фотографиям Бориса: чёрно-белый пушистый кот с зелёными глазами, белой грудью и лапами, розовым носом, лежащий на шалфейно-зелёной книге; мягкая гуашь, прозрачный фон, без надписей. Исходные фотографии в репозиторий не включены.
